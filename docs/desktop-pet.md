# 爱弥斯桌宠（P0 / P1 / P2）

桌宠和性能监控、ESP32 语音助手运行在同一个 Aemeath 桌面应用中。它是附加的原生透明窗口，不替换监控页面，也不另建一套语音助手。

## 使用

- 启动时挥手；单击挥手，双击跳跃，按住拖动可移动位置。
- 空闲时短距离散步；鼠标悬停会停下。右键打开原生菜单，也可使用现有托盘中的「爱弥斯桌宠」。
- 「允许桌面散步」关闭后定点待机；「暂停自主活动」只暂停自动动作，不妨碍手动互动和助手状态显示。
- 可独立设置显示、始终置顶、角色大小（75% / 100% / 125% / 150%）及散步频率。
- 「显示桌宠 / 恢复鼠标交互」会显示角色、取消鼠标穿透，并把角色找回当前可见工作区。主应用菜单「桌宠」也提供找回 / 隐藏入口，托盘不可用时仍可恢复。
- 鼠标穿透是**整个角色窗口**的开关，不是逐像素透明命中。开启后从托盘恢复；托盘创建失败时禁止开启。穿透状态不写入配置，每次重启恢复交互。
- 气泡是单独的小窗口，隐藏时不留下额外的大块透明遮挡区。角色本体仍是完整的 192×208 像素格子按比例显示，不裁掉动作。

## 离线与助手联动

没有 ESP32、网络、API Key 时，角色显示、点击、双击、拖动、待机和散步仍可使用。桌宠不会主动录音、发起聊天、合成声音或调用收费接口。

当现有 ESP32 助手已启用并连接时，桌宠只订阅同一份状态：聆听 / 识别显示等待动作，思考 / 合成显示处理中，播报显示回应，错误播放一次失败动作后恢复桌宠活动。错误提示和短回复气泡最长显示 6 秒，最多 80 个 Unicode 字符；重复状态不会无限续期。

「完整对话」打开现有主窗口的「语音助手」页面；「取消当前请求」调用现有的取消入口，不启动第二个会话。上下文菜单及气泡携带会话和轮次，过期操作不会取消更新的一轮。启动、重连不会重播保留的旧回复。

此阶段不增加无硬件聊天、电脑麦克风或电脑音频输出（P3 不在范围内）。

## 配置与恢复

设置保存在应用用户数据目录独立的 pet.json，不修改性能监控和语音助手设置。位置保存采用防抖，拖动结束与退出时落盘；使用同目录临时文件与原子重命名，文件权限为 0600。损坏配置先用默认值运行，未明确修改设置前不会自动覆盖原损坏文件。

屏幕坐标统一使用 DIP，而不是截图的物理像素。布局按每一块显示器的工作区分别计算，支持左侧/上方负坐标；拔屏或改变分辨率会重新约束位置。找回入口取消穿透和暂停，并置于可见工作区。

隐藏角色会停止动画 tick 向 UI 派发；不会创建第二个助手事件消费者。退出停止 ticker、屏幕监听和气泡窗口。

## 资源与实现

动作来自已有 [原始精灵图](../firmware/main/assets/avatar_source/spritesheet.webp)，原样保持 192×208 的整格与九行动作。有效帧数为 6 / 8 / 8 / 4 / 5 / 8 / 6 / 6 / 6（共 57 帧，15 个空格）。挥手每帧 140ms，其余 150ms，与固件保持一致。

资源生成器只把全透明像素的不可见 RGB 清零，避免错误预乘显示出原图隐藏彩条；不涂黑背景、不改角色轮廓、不按 alpha 裁切。可复现命令（在 agent 目录）：

~~~sh
go generate ./internal/pet
go test ./internal/pet ./scripts/pet-assets
~~~

详见 [验收记录与平台边界](desktop-pet-validation.md)。
