# 监控台远程切页

Agent 在现有设备 WebSocket（`ws://<host>:<port>/ws`）上发送控制帧：

```json
{"v":1,"type":"display","page":"metrics"}
{"v":1,"type":"display","page":"quota"}
{"v":1,"type":"display","page":"voice"}
```

固件只接受数值版本 `1` 和上述三个页面名称。接收后在 LVGL 锁内切换到性能页、AI QUOTA 页或爱弥斯语音页，不改变指标与额度快照；非法版本/名称不触发切换。屏幕左右手势仍然可用，设备重启默认显示性能页。语音唤醒自动切到角色页，完成后延时恢复原页；会话期间手动切页优先，不会在完成时被强行切回。

此协议没有 ACK 或当前页面回报。桌面端显示的是最后发送的切页指令，不能确认屏幕当前实际页面，也不会追踪用户之后的手势。断线时操作返回错误；重新连接时桌面端会发送内存中最后选择的页面（首次默认为性能页），之后也可手动切换。

订阅仍通过原 `type: "quota"` 帧同步：先按本地账户名偏好排序并过滤隐藏项，再适配设备的 ASCII 字体及长度限制，最多发送 8 个账户、每个账户最多 8 个窗口。固件按入站账户顺序显示，不再强制余额账户排在前面。空账户数组用于清空订阅显示。

远程切页和自定义账户顺序需要刷入本次更新后的固件；旧固件可继续接收性能和额度数据，但不支持切页控制。桌面端本地配置不会上传到 Magpie，也不会删除网关中的订阅。
