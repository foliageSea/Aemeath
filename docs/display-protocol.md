# 监控台远程切页与页面状态回传

Agent 在现有设备 WebSocket（`ws://<host>:<port>/ws`）上发送控制帧：

```json
{"v":1,"type":"display","page":"metrics"}
{"v":1,"type":"display","page":"quota"}
{"v":1,"type":"display","page":"voice"}
```

固件只接受数值版本 `1` 和上述三个页面名称。接收后在 LVGL 锁内切换到性能页、AI QUOTA 页或爱弥斯语音页，不改变指标与额度快照；非法版本/名称不触发切换。屏幕左右手势仍然可用，设备重启默认显示性能页。语音唤醒自动切到角色页，完成后延时恢复原页；会话期间手动切页优先，不会在完成时被强行切回。

## 当前页面回报

新固件在同一 `/ws` 通道发送页面快照：

```json
{"v":1,"type":"page_state","page":"quota"}
```

`page` 只能为 `metrics`、`quota`、`voice`，表示 LVGL 实际激活的页面，不是最近收到的目标指令。连接握手后上报当前快照；手势切页、远程切页、语音临时进入角色页和完成后恢复页面，均通过相同路径上报。重复快照允许，连续快速变化可能合并为最新状态；Agent 接收侧对页面与亮度/电源状态分别保留最新待处理值，暂时来不及消费时不会被其他消息挤掉最终快照。无需 Agent 轮询，也不把页面状态发送到独立的 `/voice` 音频通道。页面尚未初始化时不虚构默认值，待初始化后上报。

Agent 只根据有效的设备回报高亮页面；发送切页指令成功不等于设备已切换，不会乐观覆盖回显。未收到回报、断线或等待新连接回报时，显示“页面未知”，无默认高亮；连接就绪时仍可明确点击任意页面。非法版本/页面及旧连接的迟到回报忽略，接收状态不触发反向切页。

Agent 启动、重启、暂停后恢复和断线重连，都不自动发送默认页面或重放上次请求，保留监控台当前页面。`page_state` 是异步实际状态回报，不是带请求 ID 的逐条命令 ACK；语音工具仍只报告已发送指令，不等待状态回报。

## 版本兼容

页面回显需要同时更新 Agent 与固件。旧 Agent 会忽略新增的 `page_state` 帧；新 Agent 连接支持切页但不回传状态的旧固件时，显示“页面未知”，明确切页仍可用，已有亮屏/息屏与亮度回显不受影响。

订阅仍通过原 `type: "quota"` 帧同步：先按本地账户名偏好排序并过滤隐藏项，再适配设备的 ASCII 字体及长度限制，最多发送 8 个账户、每个账户最多 8 个窗口。固件按入站账户顺序显示，不再强制余额账户排在前面。空账户数组用于清空订阅显示。

仅升级 Agent 不会让旧固件获得页面回报能力；请按当前固件分区布局升级应用固件，无需因为本功能清空 NVS。桌面端本地配置不会上传到 Magpie，也不会删除网关中的订阅。
