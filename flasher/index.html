Aemeath 网页刷机

Waveshare ESP32-S3-Touch-LCD-4B · 通过浏览器 USB 串口直接刷入固件，无需安装 ESP-IDF

当前浏览器不支持 Web Serial。请使用桌面版 Chrome 或 Edge（89+），并通过 HTTPS 或 localhost 打开本页。

1连接设备

用 USB-C 数据线连接开发板，点击“连接”，在弹窗中选择 ESP32-S3（USB JTAG/serial debug unit）。

连接失败？手动进入下载模式
  1. 按住板上的 BOOT 键；
  2. 短按一下 RESET（RST） 键；
  3. 松开 BOOT，再点击“连接”。

另外请确认已关闭 idf.py monitor、串口助手等占用串口的程序，并使用支持数据传输的 USB 线。

分区偏移文件大小

选择 ESP-IDF 构建产物，文件名会自动推断偏移：bootloader → 0x0，partition-table → 0x8000，其他 → 0x10000（app）。合并镜像（merge_bin）请填 0x0。
